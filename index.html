Що вміє програма YilitNes

Програма створена для швидкого обслуговування Windows без складних налаштувань і фонових служб.

Модуль 01

Моніторинг ресурсів та очищення ОЗП

Показує актуальне завантаження процесора, оперативної пам'яті та диска у відсотках і гігабайтах.

  • Інформація про модель CPU, обсяг ОЗП та версію ОС
  • Очищення робочих наборів процесів через WinAPI EmptyWorkingSet
  • Зменшення споживання пам'яті перед запуском ігор або важких програм
Модуль 02

Очищення системного сміття та кешу

Сканує тимчасові папки Windows та кеш популярних браузерів, показуючи точний розмір файлів перед видаленням.

  • Папка користувача %TEMP% та системна папка Windows Temp
  • Кеш браузерів Google Chrome, Microsoft Edge та Mozilla Firefox
  • Очищення кошика на всіх локальних дисках в один клік
Модуль 03

Диспетчер процесів і пріоритетів

Повний список запущених процесів із відображенням PID, видавця, використаної пам'яті та поточного пріоритету.

  • Зміна пріоритету процесу: Low, Below Normal, Normal, Above Normal, High, Realtime
  • Фільтр та підсвічування довірених процесів за назвою видавця
  • Миттєве примусове завершення завислих програм
Модуль 04

Автозавантаження та швидкі дії

Допомагає прискорити запуск Windows і вирішувати типові збої системи однією кнопкою.

  • Зручні перемикачі для вмикання та вимикання програм в автозавантаженні
  • Швидкий перезапуск Провідника Windows (explorer.exe)
  • Очищення кешу DNS та активація схеми живлення «Висока продуктивність»

3 кроки для правильного запуску:

1. Завантажте файл

Натисніть кнопку завантаження вище та збережіть інсталятор або архів на ПК.

2. Підтвердіть запуск у Windows

Якщо з'явиться вікно SmartScreen («Windows захистила ваш ПК»), натисніть «Докладніше» → «Виконати в будь-якому разі».

3. Запускайте від імені адміністратора

Для очищення системної папки Windows Temp, зміни високих пріоритетів та скидання DNS потрібні права адміністратора.

Як користуватись програмою

Оберіть потрібний розділ меню YilitNes, щоб переглянути покрокову інструкцію.

Як звільнити оперативну пам'ять (Вкладка «Моніторинг»)

На головному екрані програми відображаються кругові індикатори завантаження процесора, ОЗП та диска.

1
Перевірте поточне навантаження Подивіться на центральний індикатор «Оперативна пам'ять», де вказано зайнятий обсяг (наприклад, 8,8 GB із 15,8 GB).
2
Натисніть синю кнопку «Очистити ОЗП» Програма викличе системну функцію WinAPI EmptyWorkingSet і вивантажить невикористовувані кешовані дані фонових програм.

Як очистити тимчасові файли та кеш (Вкладка «Очищення»)

Цей розділ дозволяє безпечно видалити накопичене сміття системи та браузерів.

1
Натисніть кнопку «Сканувати» Програма перевірить папки %TEMP%, Windows Temp, кеш Chrome/Edge/Firefox та Кошик і покаже обсяг кожного пункту.
2
Позначте галочками потрібні категорії Залиште активними ті пункти, які хочете очистити (наприклад, залиште Кошик знятим, якщо там є важливі файли).
3
Натисніть «Очистити» Після завершення вгорі з'явиться повідомлення з точним обсягом звільненого місця на диску.

Як керувати процесами та їх пріоритетом (Вкладка «Процеси»)

Допомагає виділити більше ресурсів процесора для гри чи робочої програми або закрити завислий процес.

1
Знайдіть потрібний процес у таблиці Використовуйте рядок пошуку або сортування за пам'яттю, назвою чи PID.
2
Змініть пріоритет на панелі зверху Клікніть по процесу та натисніть одну з кнопок пріоритету (Low, Normal, High тощо). Уникайте Realtime для важких ігор, щоб не завис інтерфейс.
3
Завершення процесу Якщо програма не відповідає, виділіть її та натисніть «Завершити» (End Task).

Автозавантаження та швидкі системні дії (Вкладка «Автозавантаження»)

Прискорює завантаження Windows при ввімкненні комп'ютера.

1
Вимкніть зайві програми при старті Переведіть перемикач навпроти непотрібної програми в неактивне положення — вона більше не запускатиметься автоматично разом із Windows.
2
Використовуйте картки швидких дій Натисніть «Перезапустити» біля Провідника, якщо зависла панель завдань, «Очистити» біля DNS при проблемах з інтернетом або увімкніть схему живлення «Висока продуктивність».

Мова інтерфейсу та довірені процеси (Вкладка «Налаштування»)

Налаштуйте програму під себе в два кліки.

1
Зміна мови без перезапуску Оберіть English, Українська або Русский — інтерфейс миттєво перекладеться.
2
Список довірених видавців Вкажіть назву компанії-розробника (наприклад, NVStudio або Microsoft), щоб її процеси позначалися у диспетчері як довірені.

Часті запитання

Так. Очищення ОЗП використовує стандартний механізм Windows API (EmptyWorkingSet), який не закриває відкриті програми, а лише звільняє невикористовуваний кеш пам'яті. У папках Temp видаляються лише тимчасові файли, які не заблоковані системою.
Файли, які прямо зараз використовуються активними службами Windows або відкритими програмами, заблоковані системою. YilitNes автоматично пропускає їх, щоб не порушити стабільність роботи ПК.
Для перегляду моніторингу та очищення %TEMP% користувача права адміністратора не обов'язкові. Проте для очищення системної папки C:\Windows\Temp, скидання кешу DNS та зміни пріоритету системних процесів бажано запускати YilitNes від імені адміністратора.
